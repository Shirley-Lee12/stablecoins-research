关于稳定币

稳定币发展历程

稳定币出现时间不长，但它试图解决的问题并不新。私人货币型债权、电子价值与分布式结算逐步汇合，随后又受到市场危机与监管制度的共同重塑。

三条传统汇成稳定币

这些线索是制度与技术思想的来源，并不表示直接的历史继承；现代稳定币选择性地重组了三者的特征。

货币制度传统

存款、货币发行局、离岸美元和货币市场基金建立了债权、储备、面值赎回与挤兑的制度逻辑。

电子价值传统

电子货币与预付价值使货币债权脱离实体现金，并突出发行人责任与资金保护问题。

分布式结算传统

公共区块链加入可编程所有权、持有人式转移、可组合性以及共享账本上的结算。

重组结果

稳定币安排

可转移代币在可编程结算网络上，将锚定价值与支撑、赎回、治理和市场流动性连接起来。

BEFORE 2008

货币与制度前史

稳定币并未发明私人货币或按面值赎回，而是把既有的货币承诺与新的结算网络重新组合。

19th–20th c.

私人货币型债权构成经济上的类似物

银行存款、货币发行局、离岸美元和货币市场基金份额都体现了反复出现的结构：私人管理的债权承诺按面值兑换为更基础的货币。

这些是制度类似物，而非直接祖先；它们帮助解释现代稳定币的储备质量、流动性、赎回与挤兑风险。

BIS, 2023
BIS, 2024

1993–2000

电子货币使货币价值脱离实体现金载体

欧洲中央银行在20世纪90年代研究预付卡和软件型电子货币；欧盟首部电子货币指令随后将其界定为对发行人的债权，由收到资金后发行，并可由第三方接受。

早在公共区块链出现之前，发行人债权、资金保护、审慎监管和按面值赎回就已经是政策问题。

ECB, 1998
European Union, 2000
02

2008–2013

链上结算基础形成

公共区块链使稀缺数字资产能够在没有中央账本运营者的情况下转移，但价格波动留下了缺失的稳定货币层。

2008–2009

比特币证明点对点数字结算可以运行

比特币白皮书提出以点对点网络而非受信任金融中介为基础的电子现金，网络于2009年启动。

突破在于转移轨道与账本架构，而非价格稳定；其波动性随后催生了对可在同类网络流通的稳定计价单位的需求。

市场支持型实验、法币储备发行人与链上抵押协议相继出现，构成现代稳定币的主要设计谱系。

BitUSD 与 Tether 开启现代稳定币时代

两条延续至今的路径几乎同时出现：加密原生稳定机制与发行人管理的储备支持。

监管者开始审视发行人、储备、治理、钱包和转移系统构成的整体安排，而不只是代币本身。

稳定币类别

依据价值支撑和恢复锚定的方式划分稳定币，同时保留锚定对象与使用权限信息。机制标签描述经济设计，并不等同于法律属性或安全评价。

用四个问题理解稳定币

四个问题彼此关联：锚定对象界定承诺，价值支撑与使用权限决定赎回和套利能否发挥作用，稳定机制再将这些条件转化为可持续的锚定。

机制详解

算法型

主要依靠供给规则与套利激励维持锚定，并不具备充分且可随时赎回的储备。

代表项目

UST 与 FEI 作为历史案例保留；FRAX 则代表机制随时间演变的项目。

机制如何运行

以下为简化运行路径，具体项目的实现可能存在差异。

01

观察市场价格

02

触发规则或套利

03

扩张或收缩供给

04

交易配对资产

05

尝试恢复锚定

稳定原理

机制可能调节供给、使用双代币结构，或结合部分抵押与算法控制；不同子类型不能视为完全相同。

赎回路径

恢复锚定往往依赖市场激励或兑换为另一代币，而非对发行人的直接赎回请求。

风险传导

反身性挤兑、套利容量不足、信心冲击、治理干预及死亡螺旋。

具有机制实验价值

失效路径

信心与支撑资产价值同步下降
压力期套利能力消失
