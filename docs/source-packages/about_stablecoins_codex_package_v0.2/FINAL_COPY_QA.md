## Conceptual boundaries
The following are frozen:
- stablecoin ≠ CBDC;
- stablecoin ≠ tokenised commercial-bank deposit;
- stablecoin ≠ tokenised fund share;
- application ≠ adoption;
- attestation ≠ audit;
- reserve backing ≠ identical direct issuer redemption rights;
- synthetic/hedged ≠ classic endogenous algorithmic design;
- algorithmic ≠ decentralised;
- current economic mechanism takes precedence over historical project label.
