# A. `/regional-developments`｜亚洲稳定币发展

## HERO
**H1** 亚洲不是一条统一的稳定币路线

**Lead**
中国内地、香港、新加坡和阿联酋都在建设数字货币与链上金融基础设施，但对私人稳定币采取了完全不同的制度路径。真正需要比较的不是“谁更开放”，而是：谁允许发行、谁已经发牌、token 是否真的上线、谁能使用，以及资金在哪个监管边界内流通。

## A1｜四条不同路线
### 中国内地
私人稳定币：禁止 / 严格限制  
数字货币主线：e-CNY

### 中国香港
专门发牌制度：已实施  
产品：进入分阶段发行  
HKDAP 已进入机构/企业 Beta Access；HSBC RedCoin 已命名但尚未发行。

### 新加坡
框架设计：成熟  
专门制度实施：仍在立法咨询  
XSGD/XUSD 已在现有 PSA/DPT 体系下运行，但不等于 MAS-SCS issuer framework 已全面生效。

### 阿联酋
产品活跃，但监管是多辖区结构  
CBUAE 管理 onshore Payment Tokens；VARA、ADGM/FSRA、DIFC/DFSA 各有不同边界。AE Coin 与 Zand AED 已有可核实 AED stablecoin 产品。

**Visual** REG-M01

## A2｜从规则看到真实可用
使用 `REGULATORY_MATRIX.csv` + `PRODUCT_AVAILABILITY.csv`，默认比较：
issuer regime / licensed issuer / token live / current access / distribution channel / payment use / stablecoin-CBDC distinction。

## A3｜四个常见误区
1. “中国禁止稳定币，所以没有数字货币发展。”——错误，e-CNY 是不同制度路线。
2. “香港发了两张牌，所以两个 token 都已面向公众。”——错误。
3. “StraitsX/Circle 有 MAS 牌照，所以 token 已是 MAS-SCS regulated stablecoin。”——错误。
4. “UAE stablecoin 都由 VARA 管。”——错误。

# B. `/mainland-china`｜中国内地

## HERO
**H1** 中国内地的路径不是“私人稳定币 + 牌照”，而是“私人虚拟货币高压管控 + e-CNY”

**Lead**
2026 年最新通知把稳定币、境外人民币稳定币、境外虚拟货币发行与 RWA 代币化纳入更明确边界；与此同时，数字人民币继续作为央行法定数字货币推进跨境零售使用。

## B1｜2026 年规则
- 虚拟货币不具有法偿性；
- 境内相关金融业务被禁止；
- 境外主体不得非法向境内提供相关服务；
- 未经同意不得在境外发行挂钩人民币的稳定币；
- 未经同意，境内主体及其控制的境外主体不得在境外发行虚拟货币；
- 金融/支付机构不得提供账户、划转、清算结算支持；
- RWA tokenisation 进入更明确监管边界。

当前基线：银发〔2026〕42号；2021 旧通知已废止。

## B2｜三个概念不要混
**Private stablecoin**：当前内地不存在面向公众的合法私人稳定币发行交易市场。  
**e-CNY**：PBOC 发行的 CBDC/法定数字货币，不是 stablecoin。  
**Approved tokenised infrastructure**：RWA tokenisation 原则受限，但存在主管部门同意、特定金融基础设施边界。

**Visual** REG-D01

## B3｜跨境 e-CNY
香港试点已支持香港手机号钱包、无需内地银行账户、FPS 增值和跨境零售支付；香港钱包当前不支持 P2P。

**Key line**
中国的政策不是“拒绝数字货币”，而是对发行主体与法律属性作出不同选择。

# C. `/hong-kong`｜中国香港

## HERO
**H1** 香港已经从“写规则”进入“发牌 + 分阶段发行”

**Lead**
制度自 2025 年 8 月实施；2026 年 4 月 HKMA 发出首批两张牌照。但用户真正需要知道的是：牌照之后 token 是否发行、谁能获得、通过什么渠道使用。

## C1｜两家持牌发行人
**Anchorpoint Financial** — FRS01 — 2026-04-10 — HKDAP — `BETA ACCESS LIVE`  
**HSBC** — FRS02 — 2026-04-10 — HSBC RedCoin — `FORTHCOMING / NOT ISSUED`

## C2｜HKDAP
- 1 HKDAP = HKD1
- Beta Access: 2026-08-12
- Beta 期间 Ethereum mainnet
- select authorised distributors
- institutional/corporate users
- reserve assets 为持有人利益按信托结构持有
- Standard Chartered 为首家银行 authorised distributor

**Do not label:** Retail live

## C3｜HSBC RedCoin
截至 2026-09-30，HSBC 明确尚未在香港发行 stablecoin。

计划：
- PayMe
- HSBC HK App
- P2P
- P2M participating merchants
- tokenised investment

**Visual** REG-D02

issuer licence → token launch → authorised distributor/channel → user eligibility

# D. `/singapore`｜新加坡

## HERO
**H1** 新加坡的稳定币市场已经在运行，但专门 MAS-SCS 发牌制度仍在完成立法落地

**Lead**
MAS 2023 年完成 framework 设计；2026 年 9 月就 PS Act 修法咨询以正式实施。与此同时，XSGD/XUSD 已在现有 PSA/DPT 监管体系运行。

## D1｜两条并行轨道
**Future MAS-SCS:** 2023 framework → 2026 legislative consultation → future MAS-regulated issuer/token label  
**Existing market:** PSA → MPI/DPT → XSGD/XUSD/Circle services

**Visual** REG-D03

## D2｜XSGD / XUSD
XSGD：1:1 SGD、月度储备鉴证、1:1 赎回、live。  
XUSD：1:1 USD、月度储备鉴证、live。

正确表述：
`live under existing PSA / DPT / MPI framework`

错误表述：
`already MAS-regulated stablecoin under MAS-SCS`

## D3｜Circle / USDC
Circle Internet Singapore 是 MAS Major Payment Institution，可提供 DPT、国内和跨境转账等服务。这能证明机构受监管，不能自动证明 USDC 已获得 MAS-SCS token label。

# E. `/uae`｜阿联酋

## HERO
**H1** 阿联酋不是一个 stablecoin licence box，而是多个监管边界并存

**Lead**
AED payment token、Dubai virtual asset、ADGM fiat-referenced token 与 DIFC crypto-token activity 并不由同一监管机构负责。理解阿联酋，第一步是先看 jurisdiction 和 activity。

## E1｜四个监管边界
**CBUAE** — onshore Payment Token Services；AED payment token/payment use  
**VARA** — Dubai excl. DIFC；VA/FRVA；AED-referenced token 归 CBUAE  
**ADGM / FSRA** — FRT issuance + Accepted FRT  
**DIFC / DFSA** — Crypto Token framework

**Visual** REG-M02

## E2｜CBUAE Payment Tokens
- Regulation 自 2024-08-31 in force
- issuance / conversion / custody-transfer
- AED token issuance by licensed Dirham Payment Token Issuers
- par redemption
- no time-based interest/reward
- Financial Free Zones excluded

当前 register 包括 AED StableCoin、Zand Trust、AEDC Stable Coin。

## E3｜AE Coin
Issuer: AED Stablecoin LLC  
1 AEC = 1 AED  
状态：`LICENSED + LIVE PRODUCT + AGENT-DISTRIBUTED`  
Issuer 第一方披露 B2B-only；终端 custody/transfer/conversion 由 appointed agents 承担。

## E4｜Zand AED (AEDZ)
1 AED = 1 AEDZ；CBUAE-regulated issuer；public multi-chain；1:1 redemption；reserve transparency。  
状态：`LICENSED + LIVE PRODUCT + PUBLIC MULTI-CHAIN`

动态 reserve/circulation 数字必须带 as-of date。

## E5｜VARA / ADGM / DIFC
VARA：AED-referenced FRVA 归 CBUAE；VARA FRVA 不得用于 UAE goods/services payment。  
ADGM：Issuing FRT 是 regulated activity；Paxos USDL / Universal Digital / JD Coinlink 等 issuer permissions 必须与具体产品 launch 分开。  
DIFC：2026-01-12 更新 Crypto Token framework 生效，firms 进行 documented suitability assessment。

## E6｜核心问题
“某 token 在 UAE 合规”信息不足。必须追问：
Which jurisdiction? Which activity? Issuer or service licence? Payment or investment use? Retail or institutional?
