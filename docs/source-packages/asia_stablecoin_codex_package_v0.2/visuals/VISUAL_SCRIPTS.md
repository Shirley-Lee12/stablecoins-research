## REG-M01｜Asia Stablecoin Development Map
目的：10 秒理解四地不是同一制度阶段。
- Mainland China: private stablecoin PROHIBITED/STRICTLY RESTRICTED; e-CNY route
- Hong Kong: dedicated issuer regime LIVE; 2 licences; HKDAP Beta; RedCoin forthcoming
- Singapore: framework design FINALISED; implementation legislation CONSULTATION; XSGD/XUSD live under PSA/DPT
- UAE: multi-perimeter; CBUAE AED payment tokens live; VARA/ADGM/DIFC separate
建议用地理定位 + 四张事实卡，而不是监管“红绿灯”。

## REG-D01｜Mainland Digital Money Boundary
三条并列路径：
1. Private stablecoin / virtual currency → PROHIBITED / RESTRICTED
2. e-CNY → PBOC-issued CBDC / official digital money route
3. RWA/tokenised activity → approval-bound / specific infrastructure exception
底部：Hong Kong stablecoin licence does not create Mainland distribution permission.

## REG-D02｜Hong Kong: Licence ≠ Availability
Anchorpoint:
FRS01 → HKDAP → Beta LIVE 12 Aug → authorised distributors → institutional/corporate → retail Full Launch NOT YET
HSBC:
FRS02 → RedCoin named → PayMe/HSBC App planned → NOT YET ISSUED
必须把 licence、token launch、distribution、retail 四个节点视觉分开。

## REG-D03｜Singapore: Framework vs Live Market
Track A:
2023 MAS framework design → 2026 PS Act consultation → future MAS-SCS label
Track B:
existing PSA → MPI/DPT → XSGD/XUSD live; Circle services
中心句：Existing regulated DPT activity ≠ MAS-SCS issuer licence.

## REG-M02｜UAE Regulatory Perimeters
四框：
- CBUAE: onshore excluding Financial Free Zones; Payment Tokens; AED issuance/payment
- VARA: Dubai excl DIFC; VA/FRVA; AED FRVA -> CBUAE
- ADGM/FSRA: FRT issuance + Accepted FRT
- DIFC/DFSA: Crypto Token framework
中心问题：Which jurisdiction? Which activity? Which user?
