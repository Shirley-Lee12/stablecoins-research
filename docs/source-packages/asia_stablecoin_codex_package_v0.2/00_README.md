## 原则
1. 不照搬现有网站初稿。
2. `license ≠ token launched ≠ retail available ≠ mass adoption`。
3. CBDC ≠ stablecoin；tokenised deposit ≠ stablecoin；DPT licence ≠ MAS-regulated stablecoin issuer licence。
4. UAE 必须拆分 CBUAE、VARA、ADGM、DIFC。
5. 动态状态以 2026-10-16 为基线。
6. UNKNOWN 不自行补全。

## 四个关键结论
- 中国内地：私人虚拟货币/稳定币业务高压禁止；e-CNY 是 CBDC 路线。
- 香港：专门发牌制度已实施；Anchorpoint/HSBC 已获牌；HKDAP Beta live，RedCoin 尚未发行。
- 新加坡：2023 框架设计已定，但 2026 年实施修法仍在咨询；XSGD/XUSD 已在现有 PSA/DPT/MPI 框架下运行。
- 阿联酋：多辖区监管；CBUAE AED payment token、VARA、ADGM/FSRA、DIFC/DFSA 不能混写。
