## HOME-D01｜Research Hub Map

### Purpose
Turn the homepage from an institution-first page into a question-first entry map.

### Center
Stablecoin Research Hub

### Five branches
1. **How stablecoins work**
   reserve · collateral · redemption · arbitrage · liquidation
   → About Stablecoins

2. **Where they are actually live**
   regulation · licence · token status · user access
   → Regional Developments

3. **How AI agents can pay**
   identity · authorization · payment execution · rails
   → Agentic Payments

4. **What markets and chains show**
   supply · price stability · on-chain activity · reserves · macro · adoption
   → Market Data

5. **How risks form and propagate**
   conceptual framework · measurement · TE · Hawkes · validation
   → Research

### Visual rule
No logos, no decorative coins, no robots.
Use one central node and five research branches.
