## Scope

This package rebuilds:
- `/` — platform homepage
- `/research` — research overview

It does **not** redesign Market Data, Quantitative pages, About Stablecoins, Academic Resources, or Experts.

## Core editorial decision

The homepage should answer:

1. What can I learn here?
2. What research is already completed?
3. What evidence can I inspect now?
4. Which parts are still in progress?
5. Where should I go next?

The Research page must separate:

- **Completed conceptual research**
- **Completed / approved evidence modules**
- **Quantitative empirical work with interim results**
- **Validation / reproducibility still in progress**
- **Planned monitoring / early-warning infrastructure**

These states must never collapse into one “research platform” claim.

## Stable site identity

Keep:
- English name: `Stablecoin Research Hub`
- current Chinese name: `稳定币学术研究平台`
- restrained blue academic/finance visual language
- bilingual support
- light/dark themes
- left global navigation

Do **not** rename the site without explicit user approval.
