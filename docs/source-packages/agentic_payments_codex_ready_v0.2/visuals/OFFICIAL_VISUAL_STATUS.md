# Official Product Visual Status V0.2

The V0.2 package does **not** require third-party or reconstructed screenshots to become Codex-ready.

Official product visuals are treated as supporting evidence. If an official reusable still cannot be acquired cleanly, Codex should use the original explanatory SVG and place the official source link next to the factual claim.

| AGT-S06 | JD AI Shopping | SOURCE_ONLY | Product existence is verified; a first-party UI capture is preferred if later available. |
| AGT-S07 | UnionPay APOP case | SOURCE_ONLY | Official article verifies five production-system validation transactions. Use official event material only if reusable. |

## Non-blocking rule

A missing screenshot does not justify:
- using a news-media or social-media repost as primary product evidence;
- recreating an official UI and presenting it as a screenshot;
- generating an AI mockup that looks like the real product.

Use an original neutral schematic instead.
