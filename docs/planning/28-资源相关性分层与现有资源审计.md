# 资源相关性分层与现有资源审计

> 核对日期：2026-08-23
> 目的：避免将“稳定币直接研究”和“可复用的方法/理论背景”混在同一个公开资源列表中，同时保留 AI 误判后的申诉通道。

## 一、导入规则

### 1. 稳定币直接资料

满足下列任一条件，才进入可直接上传批次：

- 标题或正式题录明确出现“稳定币 / stablecoin”；
- 标题明确研究 USDT/Tether、USDC、DAI/MakerDAO、TerraUSD/UST、FRAX、USDe/Ethena 等稳定币项目；
- 标题采用早期或等价术语，例如 `stable cryptocurrency`；
- PDF 文件名不清晰，但首页题名区能够确认其核心研究对象是稳定币；
- PDF 与一条已确认直接相关的 Word 题录高置信匹配。

Word 题录与匹配到的 PDF 放在同一批次。未匹配到 PDF 的直接相关题录单独分批。

### 2. 方法与理论背景

下列资料不放入直接上传区，单独归入 `80_方法与背景资料_暂不直接上传`：

- 区块链、智能合约、DeFi、加密资产；
- 银行挤兑、影子银行、货币市场基金；
- 风险传染、Hawkes、转移熵、CoVaR、GARCH、图神经网络等方法；
- CBDC、数字人民币、数字支付、私人货币等相邻主题。

### 3. 明显无关

既没有稳定币直接证据，也不属于上述方法/背景范围的资料不生成上传文件，只列入 `90_明显无关_不上传.csv`。

### 4. AI 误判申诉

- 系统判断可能无关时，资源先保存为 `off_topic`，不会进入管理员审核或公开资源库。
- 用户认为判断有误时，可以在 My Contributions 填写说明并重新提交，由管理员最终判断。
- 批量“一键提交完整条目”不得自动放行 `off_topic` 项。
