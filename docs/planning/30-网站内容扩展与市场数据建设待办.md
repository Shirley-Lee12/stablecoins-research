### 稳定币发展页推荐拓展

已新增一个不重复监管页的“亚洲比较总览”，并让每个经济体采用相同的六层结构：

1. **发展阶段矩阵**：政策讨论、制度生效、发牌、产品发行、分发渠道、可量化采用分别成列。
2. **产品与发行人**：发行主体、代币、锚定货币、支持链、用户范围、赎回方式、当前状态及官网。
3. **使用与采用证据**：供应量、转账额、活跃地址、商户/机构覆盖、结算量；没有数字时明确“未公开”，不得用试点数量代替采用量。
4. **金融基础设施**：银行、钱包、交易平台、托管、代币化存款、央行结算资产分别说明角色。
5. **跨境连接**：与其他辖区、外汇制度、分销限制及互操作基础设施的关系。
6. **未来路线图**：只展示官方或主体已公开的计划，并与已完成事项分开。

现有比较表只能回答“有没有制度、牌照或产品”，不足以解释四个经济体为何选择不同路径。下一版应围绕“发展模式—参与主体—产品渠道—实际使用—下一道约束”形成阅读主线。

#### 亚洲比较总览

1. [x] **四个经济体当前结论**：中国内地＝无境内私人发行与支付路径；香港＝2 家持牌发行人、HKDAP 有限测试；新加坡＝XSGD/XUSD/USDG 已运行；阿联酋＝AE Coin/Zand AED 已上线、3 家发行主体获牌。

3. [x] **采用证据边界**：累计交易总值、具名商户、钱包入口和上线公告分别注明能证明什么、不能证明什么，不再用一句抽象结论概括。
4. **参与主体网络**：监管机构 → 发行方 → 储备/托管机构 → 分销渠道 → 最终用户。切换经济体时更新关系图，而不是再放一张长表。
5. **应用证据分层**：允许用途、已开通产品、已有渠道、可观测活动、可归因采用分别展示；避免用同一种颜色表达不同证据等级。
6. **共同约束与下一节点**：流动性、赎回、银行接入、跨境规则、零售开放和数据披露，形成可持续更新的观察板。

仍待继续：可切换的参与主体关系图、产品登记和发展时间线四泳道；这些模块需要进一步核验主体与产品级资料后再上线，不用空图占位。

- [ ] 经筛选的稳定币转账额。
- [ ] 稳定币转账笔数。
- [ ] 活跃地址数。
- [ ] 各链稳定币供应量及净变化。

第二阶段再增加：

- [ ] 铸造、销毁和 Treasury 净流量。
- [ ] CEX/DEX 交易量拆分。
- [ ] 主要稳定币池的 TVL、交易量和组成。
- [ ] 持币地址数量及 Top 10 地址集中度。
- [ ] 桥接/跨链流量；上线前先解决重复计算问题。

口径提醒必须随图表显示：

- [ ] “转账额”不等于真实支付额；交易所内部转账、自转账、机器人和 MEV 会放大原始链上数据。

### 4.4 储备与发行方

- [ ] 显示披露频率与“距上次披露天数”，但本轮不把它转成风险分数。

- [ ] EVZ 欧元波动率。

- [ ] 整理应用方向：支付、跨境贸易、代币化资产交收和金融基础设施；“已落地”与“探索中”分开展示。
- [ ] 纳入《香港数字资产发展政策宣言 2.0》及其稳定币支付应用方向。
- [ ] 解释 Project Ensemble / EnsembleTX 与稳定币、代币化存款和代币化央行货币的关系，不把它们混成同一产品。
- [ ] 持续跟踪新增牌照，但不根据申请传闻建立“准持牌人”名单。

### 7.10 新加坡

- [x] MAS 于 2023 年定稿单一货币稳定币框架，范围为在新加坡发行、锚定新元或 G10 货币的 SCS。
- [x] 框架核心包括储备资产、资本、五个工作日内按面值赎回和披露要求。
- [ ] 核验相关立法/实施细则的最新生效状态，不能只写“框架已定稿”就推断已经完整实施。
- [ ] 核验是否已有稳定币正式获得 “MAS-regulated stablecoin” 标签；DPT 服务商牌照不能替代 SCS 发行人认定。
- [ ] 区分稳定币发行、数字支付代币服务、代币化存款和 Project Guardian 项目。
- [ ] 整理应用：机构结算、跨境支付、链上资产交易和财富/基金代币化，逐项标注真实运行还是试点。
- [ ] 用 MAS 官方文件和金融机构名录作为状态主源，公司新闻只用于补充其业务计划。

### 7.11 阿联酋与迪拜

- [x] CBUAE《Payment Token Services Regulation》自 2024-08-31 起生效，覆盖发行、兑换、托管与转移等服务。
- [x] CBUAE 负责其范围内的迪拉姆支付代币；算法稳定币和隐私代币用于支付受到禁止。
- [x] Dubai VARA 负责迪拜大陆和多数自由区的虚拟资产活动，但不包括 DIFC。
- [x] VARA 的法币参考虚拟资产规则覆盖非 AED 法币参考资产；AED 参考发行由 CBUAE 管辖。
- [ ] 建立“主管机构选择器”：UAE federal/CBUAE、Dubai/VARA、DIFC/DFSA、ADGM/FSRA，避免把阿联酋写成单一监管制度。
- [ ] 以 CBUAE 最新登记册核验 AED Stablecoin L.L.C.、AE Coin 等名称、牌照与产品状态，不把公司品牌和法定许可混写。
- [ ] 整理应用：本地支付、商户收款、跨境汇款、虚拟资产交易和金融自由区机构应用。

- [ ] 跟踪储备、赎回、资本、披露和审计要求，以及实际产品覆盖渠道。
